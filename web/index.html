Vérifier cet appareil

Le client MySyncFiles doit être lancé sur ce PC.
Le navigateur peut demander l’autorisation d’accéder à cet appareil.

Une fois l’appareil reconnu et la lecture autorisée, l’accès sera ouvert pour 30 minutes.

Configurer l’accès sur cet appareil

Autorisez la lecture web avec mysync web-files enable, puis relancez le daemon. Le pont local doit être activé avec mysync web-status enable. Ces commandes nécessitent un client disposant de l’explorateur web.

Si le navigateur a refusé l’accès local, ouvrez les permissions de ce site dans sa barre d’adresse, autorisez l’accès au réseau local et réessayez.

Statut de cet appareil

Vérifiez qu’un client approuvé répond depuis ce navigateur. Le navigateur peut demander l’autorisation d’accéder à cet appareil.

Cette vérification nécessite MySyncFiles 0.3.7 ou une version ultérieure sur ce PC.

Le daemon doit être lancé. La présence navigateur est activée par défaut à partir de la version 0.3.8 ; utilisez mysync web-status enable pour la réactiver, puis relancez le daemon. Cette vérification ne donne pas accès aux fichiers.

Aucune vérification effectuée.

Une absence de réponse peut signifier que le daemon est arrêté, que l’accès est bloqué ou que le client est absent. Elle ne prouve pas une désinstallation.

La reconnaissance confirme la réponse d’une clé TPM approuvée. Elle ne garantit ni la proximité physique du TPM, ni l’intégrité du logiciel. Le statut est déclaré par le client.
